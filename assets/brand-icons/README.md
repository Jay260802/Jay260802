# Profile brand icons

Tool and technology names appear under recognizable logos in the personal profile. The logo SVGs are kept local so README rendering does not depend on external image hosts.

- Claude Code symbol: Anthropic's official [press kit](https://www.anthropic.com/press-kit)
- Most technology icons: [Simple Icons](https://github.com/simple-icons/simple-icons)
- Azure, Azure DevOps, and VS Code: [Devicon](https://github.com/devicons/devicon)
- OpenAI and Gemini model/provider marks: [Lobe Icons](https://github.com/lobehub/lobe-icons)

These marks identify tools and technologies used. They do not imply affiliation or endorsement. Brand ownership and permitted use remain with their respective owners. Simple Icons documents icon-specific licenses and sources in its [disclaimer](https://github.com/simple-icons/simple-icons/blob/develop/DISCLAIMER.md).
