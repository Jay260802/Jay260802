# Profile brand icons

The profile uses recognizable logos to identify tools and technologies, with each name shown underneath. SVGs are stored locally so the profile does not depend on external image hosts.

- Most technology icons: [Simple Icons](https://github.com/simple-icons/simple-icons)
- AI product icons: [Lobe Icons](https://github.com/lobehub/lobe-icons)

These marks identify the products used; they do not imply affiliation or endorsement. Brand ownership and permitted use remain with their respective owners.
